# Markdown 閱讀示範

這份文件用來檢查 **繁體中文與 English 混排**、閱讀分頁，以及常見 Markdown 的顯示。先在左側目錄選一個章節，再試試 `Ctrl+F` 搜尋「流水線」。

> 文件的位置決定相對連結的位置。例如 `assets/閱讀流程.svg` 就在這份文件旁邊的 `assets` 目錄中。

## 文字與清單

一般段落可以包含 **粗體**、*斜體*、~~刪除線~~ 與行內程式碼 `pc_next = pc + 4`。中英文混排時，希望 CPU、暫存器與 pipeline 都能保持清楚的字距。

1. 按 `Ctrl+P`，搜尋文件名稱。
2. 按 `Enter`，在閱讀分頁開啟。
3. 閱讀完畢後，按 `Ctrl+W` 關閉分頁。

工作清單只用於顯示文件原本的狀態：

- [x] 以分頁開啟本機 Markdown
- [x] 檢查表格與程式碼排版
- [ ] 修改這份文件後，按 `Ctrl+R` 重新載入

## 流水線範例

這裡只示範排版，不代表某一個處理器的實際設計。流水線的時序可以先用小表格描述：

| 指令 | Cycle 1 | Cycle 2 | Cycle 3 | Cycle 4 | Cycle 5 |
| --- | --- | --- | --- | --- | --- |
| `addi x1, x0, 1` | IF | ID | EX | MEM | WB |
| `addi x2, x0, 2` | — | IF | ID | EX | MEM |
| `addi x3, x0, 3` | — | — | IF | ID | EX |

下面的 SystemVerilog 區塊用來檢查語法上色與縮排：

```systemverilog
module pc_register (
    input  logic        clk,
    input  logic        reset,
    input  logic        stall,
    input  logic [63:0] next_pc,
    output logic [63:0] pc
);
    always_ff @(posedge clk) begin
        if (reset)
            pc <= 64'h8000_0000;
        else if (!stall)
            pc <= next_pc;
    end
endmodule
```
