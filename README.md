# Markdown Finder

Ubuntu 用的 Markdown 閱讀器。以 **Qt 搜尋框 + RapidFuzz** 搜尋檔名與路徑，找到文件後直接在程式內的分頁閱讀。預設搜尋整個家目錄。

支援 Markdown 顯示、多分頁、章節目錄、頁內搜尋、縮放與工作階段還原；找檔方式使用背景掃描與記憶體清單。

## 啟動

需要 Python 3.12 以上與 `uv`。在專案目錄執行：

```bash
uv sync --locked
uv run --locked markdown-finder
```

也可以使用啟動腳本：

```bash
./run.sh
```

預設搜尋 `Path.home()`，通常就是 `$HOME`。若要先測試某個資料夾：

```bash
uv run --locked markdown-finder --root ~/Documents
```

也可以直接開啟一份或多份文件。使用專案內的範例測試閱讀功能：

```bash
./run.sh --root examples examples/閱讀示範.md
```

`--root` 只指定找檔範圍，後面的檔案路徑是要直接開啟的文件。

## 加入 Ubuntu 應用程式清單

套件與啟動指令叫做 `markdown-finder`，應用程式清單顯示名稱是 **Markdown Reader**。
完成 `uv sync --locked` 後，在專案目錄執行：

```bash
python3 scripts/install_desktop.py
```

安裝後按 **Win / Super** 鍵，搜尋 `markdown` 或 `markdown-finder` 即可開啟，不需要終端機。也可以從應用程式圖示的右鍵選單釘選到 Dock。

入口安裝在目前使用者的 `~/.local/share/applications/markdown-finder.desktop`，圖示也放在使用者的圖示目錄；若設定了 `XDG_DATA_HOME`，則使用該位置。啟動入口指向此專案的 `run.sh`，移動專案後請重新執行安裝指令。

## 改版與版本號

應用程式入口直接使用這份專案。原地更新程式碼後，正常關閉並重新開啟即可，不必重新安裝應用程式入口，閱讀進度也會保留。

| 變更情況 | 更新步驟 |
| --- | --- |
| 一般功能、修正或版本號更新 | 關閉並重新開啟程式 |
| 依賴套件變更 | 在專案目錄執行 `uv sync --locked`，再重新開啟 |
| 移動專案、修改啟動入口或圖示 | 執行 `python3 scripts/install_desktop.py` |

`run.sh` 找得到 `uv` 時會自動同步環境；若桌面環境使用既有 `.venv` 啟動而沒有 `uv`，依賴變更後需要手動同步。這是本機專案更新流程，程式不會自行下載新版原始碼。

視窗右下角會顯示目前版本，點擊可開啟「關於」。終端機也能查詢：

```bash
./run.sh --version
```

版本採用 `MAJOR.MINOR.PATCH`，唯一來源是 `src/markdown_finder/_version.py`。
每次交付改版都會升版並更新 [CHANGELOG.md](CHANGELOG.md)，詳細規則記錄於 [AGENTS.md](AGENTS.md)。目前 `0.x` 階段，相容修正升 PATCH，新功能或不相容調整升 MINOR；從穩定的 `1.0.0` 起，不相容調整升 MAJOR。升版後執行 `uv lock` 與 `uv sync --locked`，確保套件與鎖定檔同步。

## 操作

| 按鍵／動作 | 功能 |
| --- | --- |
| `Ctrl+P` | 切至找檔分頁，聚焦搜尋框並選取現有文字 |
| 輸入文字 | 搜尋檔名與路徑 |
| `↑`、`↓` | 選取結果 |
| `Enter`／雙擊結果 | 在閱讀分頁開啟文件；已開啟時切至既有分頁 |
| 找檔時按 `Esc` | 返回先前閱讀的分頁；沒有可返回的分頁時清空搜尋文字 |
| `Ctrl+W` | 關閉目前閱讀分頁 |
| `Ctrl+Tab`／`Ctrl+Shift+Tab` | 切換下一個／上一個分頁 |
| `Ctrl+Page Down`／`Ctrl+Page Up` | 切換下一個／上一個分頁（含找檔分頁，首尾循環） |
| `Ctrl+F` | 搜尋目前文件內的文字 |
| `Ctrl+R` | 重新讀取目前文件 |
| `Ctrl++`／`Ctrl+-`／`Ctrl+0` | 放大／縮小／還原閱讀縮放 |
| 工具列「符合寬度」 | 依閱讀區寬度自動縮放，並顯示目前百分比 |
| `Ctrl+Shift+C` | 複製所選文件或目前閱讀文件的完整路徑 |
| `F5` | 重新掃描找檔清單 |

閱讀分頁可以拖曳調整順序，也能按分頁上的關閉按鈕。找檔分頁保留在視窗中。

「符合寬度」（Fit width）以標準閱讀寬度為基準調整比例；改變視窗大小、開關目錄或拖曳目錄分隔線時會自動更新。每個分頁各自保留此模式，重新載入文件也會保留。按 `+`、`−`、百分比按鈕或 `Ctrl+0` 會回到手動縮放；取消「符合寬度」則保留當下比例。寬表格與程式碼區塊仍可在區塊內水平捲動。

搜尋可用空白分隔多個條件，例如 `cpu pipe`；每個條件都必須匹配該文件的檔名或路徑。支援依字元順序的模糊匹配，再以 RapidFuzz 排序。這不是完整的 fzf 查詢語法。畫面最多顯示前 100 筆，並顯示符合條件的總數。

## 閱讀功能

- Markdown 由 `markdown-it-py` 解析，透過 Qt WebEngine 顯示；支援標題、段落、清單、引用、表格、刪除線及程式碼區塊。
- 使用 Pygments 顯示程式碼語法上色，並透過 `mdit-py-plugins` 支援工作清單與註腳。
- 左側章節目錄可跳到對應標題；右側捲動時會反白目前章節，並自動捲動目錄讓該項目保持可見。折疊的上層章節會自動展開。
- `Ctrl+F` 搜尋目前文件的文字，與 `Ctrl+P` 的檔名／路徑搜尋分開。
- 相對圖片與文件連結以目前 Markdown 檔案所在目錄解析。其他 Markdown 文件的連結會在閱讀分頁開啟，同一份文件不重複開分頁；支援標題錨點。
- 本機圖片可顯示；遠端圖片不會自動載入。點擊 HTTP、HTTPS 或 `mailto:` 連結時交給系統預設應用程式。
- 文件中的原始 HTML 以文字呈現，不會當成 HTML 執行。Mermaid 與數學公式尚未加入。
- 已開啟的文件會監控檔案及其所在目錄的變動，外部修改或原子儲存後自動重新載入；也可按 `Ctrl+R` 手動更新。重新載入時盡量保留目前捲動位置，分頁切換也會保留本次執行的閱讀狀態。
- 關閉視窗或按 `Ctrl+Q` 後，下次啟動會還原分頁順序、最後選取的分頁、各文件的捲動位置、縮放比例／符合寬度模式，以及目錄的開關與寬度。手動關閉的分頁不會再次還原。
- 閱讀狀態有變更時，每 5 秒自動保存一次，正常關閉時再保存最新狀態；強制終止時最多只能還原最後成功保存的進度。進度以文件中的捲動位置保存，若內容本身大幅修改，原來的段落位置可能改變。
- 已移動或刪除的文件在還原時會略過並顯示提示。啟動命令另外指定文件時，會在還原分頁之後開啟它們，同一份文件不會重複開啟。
- 新增或刪除文件後按 `F5` 更新找檔清單。沒有整個家目錄的即時監控。

可用 [閱讀示範](examples/閱讀示範.md) 檢查中文排版、表格、程式碼、工作清單、註腳、圖片與跨文件連結。

## 掃描與資料保存

- 每次啟動都在背景掃描。找到的路徑會逐批加入記憶體，因此掃描期間就能搜尋。
- 搜尋 `.md`，副檔名不分大小寫；包含隱藏目錄，不套用 `.gitignore`。
- 不跟隨指向目錄的符號連結，避免循環與重複遍歷。無法存取的項目會跳過並計數。
- 指向一般檔案的符號連結會以連結名稱列入（目標可能在搜尋範圍外）；失效的連結會跳過。
- 找檔只使用路徑，不讀取 Markdown 內容；開啟閱讀分頁時才讀取所選文件。
- 不保存檔案索引，也沒有常駐背景服務或整個家目錄的即時監控。文件新增、移動或刪除後，按 `F5` 更新清單。
- 最近開啟的路徑最多保存 40 筆，使用 Qt `QSettings` 的本機 INI 設定檔；這份紀錄與完整檔案索引不同。

Ubuntu 預設設定檔為 `~/.config/MarkdownFinder/MarkdownFinder.conf`（若指定 `XDG_CONFIG_HOME`，則使用該設定目錄）。其中保存最近開啟的路徑、視窗位置，以及 `reader_session` 閱讀工作階段（文件路徑與閱讀設定，不保存文件內容）。`Ctrl+P` 是視窗內快捷鍵。

首次結果出現的時間與完成掃描的時間，取決於家目錄大小、磁碟及掛載目錄的狀態。模糊搜尋在已找到的清單上執行；掃描速度與輸入後的搜尋速度是兩件事。

## 開發與測試

主要依賴為 PySide6（Essentials 與含 WebEngine 的 Addons）、RapidFuzz、markdown-it-py、mdit-py-plugins 與 Pygments，版本由 `uv.lock` 固定。

```bash
QT_QPA_PLATFORM=offscreen QTWEBENGINE_CHROMIUM_FLAGS='--disable-gpu' \
  uv run --locked python -m unittest discover -s tests -v
```

上述指令使用 Qt 的離屏模式執行測試；保留 WebEngine 的 sandbox。實際字型、圖片排版、分頁操作與外部連結，仍需在 Ubuntu 圖形桌面確認。
